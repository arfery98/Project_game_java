# Fish Goes Fishing

EGCO 213 Group Project 3. A fishing game written with Java Swing only (no JavaFX, no external libraries).
All graphics and sounds are drawn and synthesized in code, there are no image or sound files.

## Run
Java 17 or newer.

```bash
javac -encoding UTF-8 -d out src/main/java/Project3_6813112/*.java
java -cp out Project3_6813112.MainApplication
```

Start class: `Project3_6813112.MainApplication`
